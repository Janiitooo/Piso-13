# Piso-13

THE LINK IS: https://github.com/Janiito-Studio/Piso-13

The public repository for Piso 13, a retro horror game created by Jan Lamarca and the team (Jaime Gaming). You play as Jan Lamarca, a resident of the Aurora Residence, as you return to the mysterious 13th floor, 25 years after a devastating fire. Something about the building feels wrong, and the doorman doesn't seem to remember you.
